## 🚀 Featured Projects

### 1. RideFlow – Real-Time Ride Platform

[![RideFlow](https://img.shields.io/badge/GitHub-RideFlow-blue?logo=github)](https://github.com/abhinav0988/rideflow)

**Tech Stack:** Node.js · TypeScript · PostgreSQL · Redis · RabbitMQ · Socket.IO

A backend-focused ride-booking platform demonstrating real-time driver discovery, concurrency control, and reliable asynchronous processing.

**Key Features:**
- Implemented nearby-driver discovery using Redis GEO and TTL-based driver presence.
- Prevented double ride assignment using Redis SET NX and PostgreSQL conditional updates.
- Implemented transactional outbox for reliable event publishing.
- Integrated RabbitMQ publisher confirms for at-least-once delivery.
- Added request idempotency and consumer deduplication.
- Implemented retry mechanisms and dead-letter handling.
- Enabled cross-server Socket.IO communication using the Redis adapter.
- Tested concurrency and failure scenarios using Jest and Testcontainers.

**Repository:** [View RideFlow](https://github.com/abhinav0988/rideflow)

### 2. Shortify – URL Shortener & Analytics Platform

[![Shortify](https://img.shields.io/badge/GitHub-Shortify-blue?logo=github)](https://github.com/abhinav0988/shortify)

**Tech Stack:** Node.js · TypeScript · Fastify · MongoDB · Redis

A backend URL-shortening service with analytics, caching, and shared rate limiting.

**Key Features:**
- Developed REST APIs for URL shortening, custom aliases, redirects, and analytics.
- Implemented 7-character Base62 short-code generation.
- Ensured short-code uniqueness using MongoDB unique indexes and bounded retries.
- Implemented Redis cache-aside strategy with MongoDB fallback.
- Built atomic fixed-window rate limiting using Redis Lua scripts.
- Developed click analytics using event records and MongoDB aggregations.
- Tested with real MongoDB and Redis using Jest and Testcontainers.

**Repository:** [View Shortify](https://github.com/abhinav0988/shortify)
